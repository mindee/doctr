docTR: Document Text Recognition#

Open-source OCR · Powered by PyTorch

OCR made seamless & accessible to anyone

docTR reads PDFs and images and gives you back every word with its position, organized into lines, blocks, layout regions and tables. Run state-of-the-art models in three lines of Python, fine-tune them on your own documents and ship them anywhere.

Get started → User guide GitHub
$ pip install python-doctr
ocr.py
from doctr.io import DocumentFile
from doctr.models import ocr_predictor

model = ocr_predictor(pretrained=True)
doc = DocumentFile.from_pdf("invoice.pdf")
result = model(doc)

# or export to JSON, Markdown, HTML...
print(result.render())

Everything you need to read documents

From a scanned receipt to a hundred-page report: docTR covers the whole pipeline, and every stage can be swapped, tuned or retrained.

Two-stage OCR

A text detection model finds the words, a recognition model reads them. Mix and match 9 detection and 9 recognition architectures.
