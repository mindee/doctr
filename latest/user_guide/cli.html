Command-line interface#

doctr-cli runs the complete OCR pipeline on images and PDFs from your terminal, and writes the result as JSON, plain text, Markdown, AsciiDoc, HTML or hOCR. It is installed with the package.

doctr-cli --input_path invoice.pdf --output invoice.json

Common recipes#

doctr-cli --input_path scan.jpg --output scan.txt

doctr-cli --input_path report.pdf --detect_tables --output report.md

Every page of every input is appended to a single document:

doctr-cli --input_path page1.jpg page2.jpg annex.pdf --output dossier.json

doctr-cli --input_path skewed.pdf --straighten_pages --output skewed.txt

On a CUDA device of compute capability 8.0 or newer, the models run in bfloat16:

doctr-cli --input_path doc.pdf --device cuda:0 --output doc.xml

Requires the html extra:

doctr-cli --input_path https://www.example.com --output page.md

The format is inferred from the extension of --output (.json, .txt, .md, .adoc, .html, .xml) and falls back to JSON. Use --format to set it explicitly.

Output files#

  • JSON contains the full structure: pages (dimensions, orientation, language, layout), blocks, lines and words with their confidence and geometry, and the tables with --detect_tables.

  • Text-like formats (txt, md, adoc, html) are written to a single file.

  • hOCR describes one page per file: --output doc.xml on a three-page document writes doc_page_1.xml, doc_page_2.xml and doc_page_3.xml.
