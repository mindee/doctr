Task-specific predictors#

The OCR predictor chains several models. Each of them is also available on its own, wrapped in a predictor that handles pre-processing, batching and post-processing. Use them when you only need one step: locating text, reading pre-cropped words, classifying orientations…

All of them take a list of images (NumPy arrays of shape (H, W, 3), uint8, RGB) and return one result per image. As with the OCR predictor, pass pretrained=True to load trained weights.

Text detection#

from doctr.io import DocumentFile
from doctr.models import detection_predictor

predictor = detection_predictor("fast_base", pretrained=True)
pages = DocumentFile.from_pdf("invoice.pdf")
out = predictor(pages)

boxes = out[0]["words"]  # (N, 5): xmin, ymin, xmax, ymax, score (relative coordinates)

With assume_straight_pages=False, each box is a rotated polygon: the array has shape (N, 5, 2), with the four corners followed by the score. Multi-class detection models (see Key information extraction) return one entry per class.

The predictor accepts the same input options as the OCR predictor: assume_straight_pages, preserve_aspect_ratio, symmetric_pad and batch_size.

Text recognition#

The recognition predictor reads one word per image. Crops are resized to the input size of the model (32 px high), so they should be tightly cropped around the word:

from doctr.models import recognition_predictor

predictor = recognition_predictor("crnn_vgg16_bn", pretrained=True)
out = predictor([word_crop])  # e.g. the crop of "ACME" from the sample invoice

print(out)  # [('ACME', 0.9996)]

Note

The pretrained vocabularies have no space character: feed the predictor single words, not whole lines. To read lines or pages, use the OCR predictor, which detects the words first.

Very wide crops are split into overlapping parts that are read separately and merged. batch_size (default 128) sets how many crops are processed at once.

Orientation classifiers#

Two lightweight classifiers predict the orientation of a page or a word crop among 0°, 90°, 180° and 270°:

from doctr.models import crop_orientation_predictor, page_orientation_predictor

page_classifier = page_orientation_predictor(pretrained=True)
class_idxs, angles, probs = page_classifier([upright_page, rotated_page])
print(angles)  # [0, -90]

crop_classifier = crop_orientation_predictor(pretrained=True)
class_idxs, angles, probs = crop_classifier([word_crop, upside_down_crop])
print(angles)  # [0, 180]

They are used by the OCR predictor for rotated documents, and can be retrained on your data.

Accessing the models#

Every predictor exposes its model as .model, a regular PyTorch module:

predictor = detection_predictor("db_resnet50", pretrained=True)

predictor.model  # the DBNet module
predictor.model.cfg  # its configuration (input shape, mean/std, url...)
predictor.model.postprocessor.bin_thresh  # post-processing parameters

The Using standalone predictors notebook shows these predictors in action.
