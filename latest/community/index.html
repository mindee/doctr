Community#

docTR is an open-source project developed in the open on GitHub. Whether you need help, want to share what you built, or would like to contribute, you are welcome here.

Discussions

Questions, ideas and show-and-tell. The best place to ask “how do I…?”.

Issues

Bug reports and feature requests. Please include the output of scripts/collect_env.py.

Contribute#

Fixing a typo, adding a vocabulary, implementing a paper: every contribution counts. The contribution guide explains how to set up a development environment, run the tests and build this documentation. Please also read the code of conduct.

Professional support#

docTR was originally created by Mindee and is now developed and maintained by t2k GmbH. t2k offers professional services around docTR:

  • Custom OCR development: detection, recognition and pipeline work tailored to your documents

  • Project implementation: turning your ideas into production-ready docTR integrations

  • Technical consulting: architecture, deployment and integration guidance

  • Ongoing development: feature extensions and implementation support

  • Workshops & advisory: hands-on sessions and recommendations for working with docTR

Contact info@text2knowledge.de or visit text2knowledge.de to discuss your project.
