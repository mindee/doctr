doctr.transforms#

Data transformations for training and inference. Inspired by torchvision, they are expressed as composable modules. Image transforms apply to the image only; sample transforms (wrapped in SampleCompose) also update the target, e.g. the boxes of a rotated image.

from torchvision.transforms.v2 import Compose

from doctr import transforms as T

img_transforms = Compose([
    T.Resize((32, 128), preserve_aspect_ratio=True),
    T.RandomApply(T.ColorInversion(), 0.1),
    T.RandomApply(T.GaussianNoise(mean=0.1, std=0.1), 0.1),
])

class Resize(
size,
interpolation=F.InterpolationMode.BILINEAR,
preserve_aspect_ratio=False,
symmetric_pad=False,
return_padding_mask=False,
)[source]#

Resize the input image to the given size

>>> import torch
>>> from doctr.transforms import Resize
>>> from doctr.utils import Sample
>>> transfo = Resize((64, 64), preserve_aspect_ratio=True, symmetric_pad=True)
>>> out = transfo(Sample(image=torch.rand((3, 64, 64))))
Parameters:

  • size (int | tuple[int, int]) – output size in pixels, either a tuple (height, width) or a single integer for square images

  • interpolation – interpolation mode to use for resizing, default is bilinear

  • preserve_aspect_ratio (bool) – whether to preserve the aspect ratio of the image, if True, the image will be resized to fit within the target size while maintaining its aspect ratio

  • symmetric_pad (bool) – whether to symmetrically pad the image to the target size, if True, the image will be padded equally on both sides to fit the target size

  • return_padding_mask (bool) – whether to return a boolean mask alongside the image, with True on valid (image content) pixels and False on padded areas. This matches how masks propagate through the other transforms (padding and rotation fill new areas with False).

  • probability (the symmetric padding will be applied with this)

  • symmetric_pad (bool | float) – whether to symmetrically pad the image,

  • value

  • probability

  • p (float) – probability to apply the transformation

class SampleCompose(transforms)[source]#

Implements a wrapper that will apply transformations sequentially on both image and target

>>> import numpy as np
>>> import torch
>>> from doctr.transforms import SampleCompose, ImageTransform, ColorInversion, RandomRotate
>>> from doctr.utils import Sample
>>> transfos = SampleCompose([ImageTransform(ColorInversion((32, 32))), RandomRotate(30)])
>>> out, out_boxes = transfos(Sample(image=torch.rand(8, 64, 64, 3), target=np.zeros((2, 4))))
Parameters:

transforms (list[Callable[[Sample], Sample]]) – list of transformation modules
