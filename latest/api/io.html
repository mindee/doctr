class Table(cells, num_rows, num_cols, geometry, confidence=1.0)[source]#

Implements a table recognized on a page as a grid of cells

The recognized text of the words falling inside the table is regrouped here and removed from the regular blocks output of the page, so it is not duplicated. The structured content can be loaded directly into pandas, e.g. pd.DataFrame(table.to_grid()).

Parameters:

  • cells (list[TableCell]) – list of TableCell objects composing the table

  • num_rows (int) – number of rows of the table

  • num_cols (int) – number of columns of the table

  • geometry (tuple[tuple[float, float], tuple[float, float]] | ndarray) – bounding box enclosing the whole table, with coordinates relative to the page’s size

  • confidence (float) – the confidence of the table structure prediction (mean of the objectness_score of its cells)

to_grid()[source]#

Return the table content as a dense num_rows x num_cols grid of strings.

Cells spanning several rows/columns have their value placed at their top-left position; the remaining positions they span are left empty. The result is directly loadable into pandas via pd.DataFrame(table.to_grid()).

Returns:

a list of num_rows lists, each of length num_cols

Return type:

list[list[str]]

class HTMLExporter[source]#

Export OCR results to semantic HTML, with the content sorted in reading order.

Headings map to <h1>/<h2>, list items to <ul><li>, recognized tables to <table> and paragraphs to <p> (with <br> between the visual lines of a paragraph). The output is a fragment, not a full document: it carries no doctype, <html> or charset declaration.

Warning

The recognized text is HTML-escaped by default. Passing escape=False interpolates the OCR output into the markup verbatim, so a document containing markup yields active HTML. Only disable escaping for output that is never rendered in a browser.

>>> from doctr.io import HTMLExporter
>>> html = HTMLExporter().export_page(page)

Figures#

Rendering of the figures found by the layout model in the Markdown, AsciiDoc and HTML exports. See Figures.

class FigureEncoder(
mode='placeholder',
image_dir=None,
path_prefix=None,
image_format='png',
quality=95,
padding=0.0,
)[source]#

Render the figures detected by the layout model in the Markdown, AsciiDoc and HTML exports

  • none: no figures

  • placeholder: a comment marks each figure

  • embedded: each crop is inlined as a base64 data URI

  • referenced: each crop is written to image_dir and linked by its relative path

With their pixels (‘embedded’ or ‘referenced’), the text recognized inside the figures is left out of the export. Written files are named after the figure position and content, e.g. page1_figure2-3fa2b1c9.png.

>>> from doctr.io import FigureEncoder
>>> markdown = page.export_as_markdown(images=FigureEncoder("referenced", image_dir="assets"))
Parameters:

  • mode (str) – one of ‘none’, ‘placeholder’, ‘embedded’ or ‘referenced’

  • image_dir (str | Path | None) – directory the crops are written to (required in ‘referenced’ mode)

  • path_prefix (str | os.PathLike[str] | None) – location of image_dir relative to the export (image_dir by default)

  • image_format (str) – one of ‘png’, ‘jpg’, ‘jpeg’ or ‘webp’

  • quality (int) – quality of the lossy formats, between 0 and 100

  • padding (float) – relative margin added around each region
